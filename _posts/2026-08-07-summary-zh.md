### [OpenAI 推出 Agent Plugins 标准](https://9to5mac.com/2026/08/06/gpt-5-turning-one-as-openai-shares-new-agent-plugins-standard/) ⭐️ 8.0/10

据该消息称，GPT-5 于 2025 年 8 月 7 日发布，在一周年前夕 OpenAI 推出 Agent Plugins，定位为开放、厂商中立的标准。该标准使用可移植插件格式打包 Agent Skills 和 MCP 服务器，使兼容客户端能够统一发现和加载相关能力。项目以公开授权方式开发，指导委员会成员包括亚马逊、Cursor、微软、OpenAI 和 Vercel。消息还称，过去一年 GPT-5 家族已迭代 5.1 至 5.6 等版本，苹果在 iOS 26 等系统中接入 Apple Intelligence，Codex 应用在今年 7 月成为新的 ChatGPT 桌面客户端；OpenAI 尚未官宣 GPT-6，但透露内部 Astra 模型推进了 10 个长期未决的数学和计算机科学问题，且 GPT-5.6 曾短暂因美国政府安全审查而推迟发布。

telegram · zaihuapd · 8月7日 00:46

**「背景」** Agent Plugins 指的是一种把 AI 代理可调用能力打包成插件的格式，目标是让同一能力可被不同客户端发现、安装和调用。MCP（Model Context Protocol）是一类让模型或代理连接外部工具、数据源和服务的接口协议；此次标准被描述为面向 Agent Skills 与 MCP 服务器的可移植封装草案，并由 OpenAI、Amazon、Microsoft、Cursor 和 Vercel 等参与治理。

**「影响」** 面向 AI Agent 工具的开发者可按 Agent Plugins 打包一次扩展，并在 Codex、Cursor、GitHub Copilot、Kiro 等兼容客户端中复用，从而减少为不同产品分别适配目录结构和安装方式的工作。
