### [xAI 发布 Grok 4.7](https://x.ai/news/grok-4-7) ⭐️ 8.0/10

xAI 发布了 Grok 4.7，引发 Hacker News 上关于其性能、价格、速度和前沿模型竞争位置的讨论。现有材料未提供官方技术细节、基准数据或能力声明，因此无法确认它相对 Grok 4.6 或其他模型的实际提升幅度。讨论中有人称 Grok 4.7 相比 Grok 4.6 参数或权重规模更大，但输入、输出 token 价格保持不变；这些说法来自社区评论，未在所给来源中得到验证。由于缺少发布说明正文，本次更新最明确的信息是新版本已发布，而其技术价值仍需更多可复现实测和官方细节支撑。

hackernews · meetpateltech · 9月21日 15:50 · [社区讨论](https://news.ycombinator.com/item?id=49788838)

**「背景」** Grok 是 xAI 推出的生成式 AI 模型系列，面向聊天、编程和代理式工作流等场景，并通过 xAI API 及部分开发工具提供访问。此类模型的商业使用通常按输入和输出 token 计费；第三方报道显示，Grok 4.7 的标准 API 价格为每百万输入 token 2 美元、每百万输出 token 6 美元，与 Grok 4.6 的基础费率相同。

**「影响」** 依赖 xAI 或 OpenRouter 接入前沿模型的开发者现在多了一个面向编码、代理任务和知识工作的 Grok 4.7 选项，其公开信息显示支持 500,000 token 上下文窗口，但实际采用仍需按自身工作负载验证成本、速度和质量。

**「社区讨论」** 评论者对 Grok 4.7 的看法分歧明显：有人欢迎 xAI 加快发布节奏并期待 Grok 5，有人则认为 4.7 更慢、token 消耗更高，实际编码和代理工作流体验仍不确定。部分讨论质疑基准测试是否能代表真实能力，并将其与传闻中的 Opus 5.5 等竞争模型作比较，但这些判断多为个人体验或推测。
