### [Claude Fable 5.1 与 Mythos 5.1 发布](https://www.anthropic.com/claude-fable-and-mythos-5-1) ⭐️ 8.0/10

Anthropic 发布了 Claude Fable 5.1 和 Claude Mythos 5.1 的相关页面，并提供 Fable 5.1 的“What&\#x27;s new”文档以及 Fable 5.1、Mythos 5.1 的 System Card。该更新受到 AI 开发者关注，因为它涉及新模型行为、评测、安全说明和可能的 API 使用成本变化。当前摘录没有给出完整官方技术参数、上下文长度、基准分数或兼容性细节，因此只能确认已有官方文档和系统卡可供进一步核查。

hackernews · denysvitali · 9月1日 17:53 · [社区讨论](https://news.ycombinator.com/item?id=49525378)

**「背景」** Claude 是 Anthropic 的大型语言模型产品线，通常以文档、API 和面向用户的产品形式发布新版本。系统卡是模型发布时用于说明能力、风险评估和安全限制的技术文档；本次材料称 Claude Fable 5.1 与 Claude Mythos 5.1 共享相同模型权重，其中 Fable 5.1 面向通用访问，并加入阻止高风险双用途知识任务的额外防护。

**「影响」** 使用 Anthropic 模型的开发者需要查看新文档和 System Card，再决定是否迁移、重新评测提示词、成本和安全行为。

**「社区讨论」** Hacker News 评论集中在 Fable 5.1 的写作风格、thinking effort 输出、缓存读取价格下降、基准改进是否充分，以及若干 breaking changes 是否是在修补意外泄露 chain-of-thought 的问题。Anthropic 员工评论称 Fable 5.1 在自然写作和遵循风格指令方面有明显改进，但其他评论者对价格信号和剔除部分测试后的性能提升提出质疑。
